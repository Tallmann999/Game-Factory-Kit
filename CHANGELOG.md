# Изменения

## Не выпущено — 5 ноября 2026

- Из карточки можно вести этап в обычном чате Codex с ходом работы и документами. При автоматическом запуске конструктор открывает чат после завершения, когда в нём уже есть читаемый ответ.

- Из карточки этапа можно запустить один сохранённый шаг в новом чате Codex и получить документы и результат обратно в карточку.
- Добавлен скилл `game-project-audit` и запуск полного аудита из конструктора. Подтверждения из существующих документов объясняют прогресс этапа независимо от того, когда был установлен набор.

- Конструктор подключается к отдельной игре и восстанавливает её этапы по документам и Feature Index. В карточках появились проценты, документы и оставшиеся шаги, над схемой — готовность к релизу и сводка для следующего чата.
- Ручной режим и Робокоп публикуют каждую принятую фичу отдельным коммитом с обновлением Feature Index в выбранные ветку и remote. При ошибке push можно повторить отправку сохранённого SHA.

- При первом открытии конструктора обучение проводит по этапам создания игры и показывает различие ручного режима и Робокопа.

- Добавлены выбор ручного режима или Робокопа, локальная доска F-ID, отдельные сессии Codex, передача контекста, приёмка и коммит каждой фичи в main игры.

- Добавлен обязательный выбор платформы, устройства и 2D/3D с автоматической настройкой скиллов следующих этапов в таблице, Markdown и CLI.

- В конструкторе появилась таблица всех 45 скиллов по этапам. Для каждого указана задача, выбранные дополнительные скиллы передаются исполнителю этапа.

- Добавлен локальный HTML-конструктор пайплайна с подвижными блоками и стрелками, зависимостями, статусами, выбором движка и настройкой исполнителей.
- Схему можно сохранить в JSON, передать координатору в Markdown или выполнять по одному этапу через Codex CLI с передачей фактических результатов между агентами.

## Не выпущено — 3 ноября 2026

- Добавлен вход «Хочу сделать игру», вопросы по 2–3 с повторным использованием известных ответов.
- Добавлены компактная доска до нового прототипа и автономный HTML-помощник без зависимостей, со схемами для проверки и сохранением выбора в JSON.
- Уточнены карта навыков по этапам, Windows/Codex, плейтест и визуальный QA; сохранён приоритет быстрого MVP с временными ассетами.
- Изменения перенесены в актуальный game-creator без восстановления устаревшего game-factory-kit. Полный движок ref2game, 3D lip sync и автопилот не включены.

## 0.2.0 — 26 октября 2026

- Предыдущий одиночный скилл заменён набором из 45 навыков; новый вход — `$game-creator` и фраза «я хочу создать игру».
- Добавлены исследование рынка и референсов, короткий концепт, Feature Index, сборка MVP и плейтест.
- Добавлены профили Web, Unity, Roblox, mobile и арт-производства, переносимый установщик, шаблоны и проверки.
- README и основные инструкции оформлены кратко на русском; старые примеры и установщик остаются в истории Git.
- Добавлены проверки Windows, Linux и macOS; тестовые временные пути нормализованы для системного `/var` на macOS.

## 0.1.0 — 28 августа 2026

- Первый скилл `$game-factory-kit`, шаблоны, пример проекта и проверки.
