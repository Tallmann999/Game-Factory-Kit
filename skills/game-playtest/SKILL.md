# game-playtest

При проверке игровой механики воспроизведи её сценарий в браузере. Для задачи об уровнях детализации используй [методику и пример отчёта LOD](references/traffic.md). Демонстрационную улицу запускай по запросу на воспроизведение именно этого опыта. Для замера конкретной игры бери её объекты, рабочие дистанции камеры и целевое устройство. Для визуальной проверки конкретного ассета используй [просмотрщик](../three-webgl-game/SKILL.md).
