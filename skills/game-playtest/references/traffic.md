# Как сравнить LOD и записать результат

Для отдельного ассета запиши число треугольников и размер GLB на каждом LOD. Сохрани один ракурс на дистанции переключения и проверь силуэт, блики и мелкие детали. Этого достаточно, когда вопрос касается размера и внешнего вида модели.

Для оценки нагрузки на сцену сделай два прохода по одному маршруту с тем же набором объектов. В первом зафиксируй самый подробный уровень, во втором включи LOD. Сохрани устройство, backend, разрешение, количество объектов и настройки эффектов. Запиши среднее число треугольников и команд рисования за кадр, а также p95 времени кадра. Меняй один параметр за раз.

| Объекты и дистанции | Режим LOD | Треугольники/кадр | Команды/кадр | p95, мс | Где видно изменение силуэта |
|---|---|---:|---:|---:|---|
| Сцена проекта | Всегда LOD0 | | | | |
| Та же сцена, тот же маршрут | Автовыбор LOD | | | | |

## Сохранённый пример с фургоном

Четыре уровня Blender-модели содержали 25 476, 8 616, 2 164 и 768 треугольников. Это измерение геометрии одного ассета. Отдельная пара прогонов с 30 экземплярами на WebGPU показала сокращение среднего числа команд отрисовки с 241,76 до 68,34 при включении инстансинга. В обоих прогонах LOD был включён, p95 составил 16,8 мс. Для оценки влияния самого LOD используй пару проходов из таблицы.

## Воспроизведение автомобильного примера

Подготовь папку [просмотрщика](../../three-webgl-game/references/model-lab.md) и скопируй в неё оба файла из [assets/traffic](../assets/traffic). Открой http://127.0.0.1:4196/street.html на том же сервере. Базовая сцена работает сразу с процедурными машинами. Для замера игровых моделей загрузи 1–4 статических GLB в порядке имён LOD0…LOD3. При одном файле переключение LOD даёт ту же геометрию. Для стекла используй подмеш или материал с названием glass, glazing, thermal, стекло либо материал с transmission.

Укажи модель устройства. Нажми «Серия» для 1, 10, 30 и 100 машин. Измени один фактор и повтори серию: LOD, прозрачность стёкол, синтетическая плазма, инстансинг. Отдельный замер доступен для выбранного количества. Стенд группирует статические детали по уровню и типу, применяет одинаковый отсев машин, ориентирует и масштабирует модель по длине до 4 м. ЛОД выбирается по расстоянию камеры. Плазма — повторяемые прозрачные конусы под двигателями; для измерения шейдера конкретной игры замени эту геометрию её эффектом.

Камера проходит одинаковые точки. На прогрев идут 30 кадров, на запись — 120. Буфер 960 × 540, DPR 1. Оставь вкладку активной. Для принудительного WebGL 2 добавь `?gl=1`. Скачай JSON: настройки, файлы моделей, устройство/браузер, фактический backend, разрешение, число образцов, среднее, p95 и максимум межкадрового интервала в мс, команд рисования и треугольников за кадр. Время включает ожидание вывода кадра и зависит от частоты экрана. Инстансинг прозрачных объектов может изменить порядок смешивания; сравни и изображение. Результаты разных устройств или backend подписывай отдельно. Для заключения по целевой игре повтори на целевом устройстве.
