# Roblox MVP

Для Roblox HUD, меню, уведомлений и кнопок управления подключи [game-roblox-ui](../game-roblox-ui/SKILL.md). Его модули описывают выбор стиля, спецификацию, геометрию Studio, временную генерацию и проверку. Подключай их только для UI текущих F-ID; фичи без UI не требуют этой процедуры.

Прочитай концепт, P0, существующие исходники, способ синхронизации и доступную сцену. Проверь реальный Studio MCP и инструменты, а не наличие слова Roblox в списке скиллов. Если Studio недоступен, подготовь проверяемые исходники и точные шаги подключения; runtime пометь not_run. Не называй сохранённый код готовым place.

Используй существующий Rojo mapping. Для новой игры синхронизируй ограниченные контейнеры кода, сохраняя пользовательские Workspace/Terrain/Lighting и импортированные объекты. Перед существенной правкой live-сцены сохрани резервную копию. Не сбрасывай DataModel и не запускай чужой bootstrap поверх проекта. Если доступен RobloxGameKit, сначала проверь версии/лицензию/module catalog: blueprint не является работающей системой; этот portable pack не включает его автоматически.

Сначала один раунд с простыми Parts, целью, действием, обратной связью, результатом и restart. Сервер владеет наградами, уроном, валютой и общим состоянием. Client→server payload недоверенный: проверяй типы, диапазоны, расстояние/ownership, контекст и частоту. Клиент отвечает за ввод, UI/камеру и локальные эффекты. Не добавляй DataStore и платежи в тест движения без необходимости.

Для импорта проверь доступность asset IDs у целевого владельца, scale/pivot/materials, rig/animation и collision в Studio. Для Blender используй `game-asset-pipeline`. Оптимизацию начинай с воспроизводимого замера: количество объектов, draw calls/overdraw, память, streaming, scripts/physics. Нужные API профилирования проверяй по фактическим возможностям Studio и актуальным официальным docs.

Проверь Play, Output, основной сценарий/ошибку/restart; для сетевого поведения — сервер и минимум два клиента. UI/тач проверяй подходящим device simulator и устройством, когда оно доступно. Сохрани исходники и локальный .rbxl/.rbxlx, если доступен корректный save workflow. В state укажи place path, текущую связь Studio/исходников и реально выполненные тесты. Публикация Experience — отдельное действие по запросу. Источники: [Creator Hub](https://create.roblox.com/docs), [Rojo](https://rojo.space/docs/).
