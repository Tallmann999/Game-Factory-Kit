# web-3d-asset-pipeline

При импорте нового или изменённого GLB в игру выполни [проверку исходника и оптимизированной копии](references/glb-audit.md). Записывай два разных бюджета: размер скачивания и объём геометрии в кадре. Если объект объединён по материалам, для точного разбора деталей возьми экспорт до объединения. Проверяй внешний вид через [сравнение A/B](../three-webgl-game/SKILL.md).
