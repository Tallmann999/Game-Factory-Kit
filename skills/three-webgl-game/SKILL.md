# three-webgl-game

Для игры на Three.js свяжи загрузку ресурсов, камеру и обновление сцены с существующим игровым циклом. Используй выбранный проектом рендерер. Для одинаковых ракурсов и сравнения ассетов используй [просмотрщик GLB](references/model-lab.md). При импорте моделей подключай [аудит GLB](../web-3d-asset-pipeline/SKILL.md), для замеров сцены — [плейтест](../game-playtest/SKILL.md).
