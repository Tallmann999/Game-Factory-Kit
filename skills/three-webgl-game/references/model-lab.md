# Просмотрщик двух моделей
Скопируй содержимое [assets/model-lab](../assets/model-lab) в отдельную папку QA проекта. В этой папке выполни:

```sh
npm ci
python -m http.server 4196 --bind 127.0.0.1
```

Открой http://127.0.0.1:4196/index.html. На входе самодостаточные GLB. Выбери для A и B по файлу или по набору LOD (числовая сортировка имён; первый — самый подробный). Размер и начало координат обоих вариантов должны совпадать. Первая модель задаёт центр и расстояние камеры. При смене A/B остаются ракурс, масштаб, нейтральное освещение и доступный выбранный LOD.

Осмотри блик и силуэт с одной позиции, поверни камеру мышью. Включи «Только стекло». Автопоиск использует название детали, материала и transmission. При необычном названии выбери материал вручную. «Свечение» переключает bloom, «Меши эффектов» — геометрию с названиями plasma, flame, particle, exhaust FX, thruster FX. Для эффектов, живущих только в коде игры, нужен адаптер этой игры.

Вариант `?gl=1` принудительно запускает WebGL 2. Без этого параметра WebGPURenderer выбирает доступный backend; в отчёт переносится фактическое значение с экрана. Пакет стенда закреплён на Three.js r185, работает локально и использует пакуемые с Three.js декодеры Meshopt, Draco и KTX2.
