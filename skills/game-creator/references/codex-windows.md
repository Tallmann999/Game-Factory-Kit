# Codex и Windows

Из корня клона `python scripts/kit.py doctor` показывает Python и пути доступных программ. Это не проверка версии движка, лицензии или живого MCP. В установленном профиле CLI может отсутствовать: проверь только необходимые программы средствами текущей сессии. Наличие навыка не означает установленный редактор.

- Для Python допустим `py -3`; помощник доски не требует Bash, WSL, Node, Blender или дополнительных пакетов.
- В PowerShell заключай пути с пробелами/кириллицей в кавычки. В Python используй pathlib и списки аргументов для subprocess вместо сборки shell-команд.
- Доска — автономный HTML. Открывай её доступным просмотрщиком/браузером; ограничения конкретного browser tool не означают, что сам файл требует сервера.
- Для игры используй её текущую команду предпросмотра. Локальный сервер слушает 127.0.0.1; запиши session/PID и останови только запущенный для этой задачи процесс. Фоновые помощники запускай без видимого окна.
- Список инструментов и навыков бери из текущего Codex. Не встраивай имена соединений с одной машины. Отсутствующую зависимость не устанавливай только потому, что она упоминается в профиле.
- Вопросы — через доступный инструмент ввода или чат; генерация — через доступный подходящий инструмент. Не запускай вложенный Claude/Codex ради генерации, автопилота или расписания.
- Для начала достаточно `$game-creator` и фразы «Хочу сделать игру». Если новый навык не появился, открой новый чат; не обещай проверенную горячую перезагрузку.

Сохраняй факты в существующей документации и state.json. Следующий чат продолжает с текущего этапа без повторной анкеты.
