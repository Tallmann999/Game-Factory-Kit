# Доска референсов до прототипа

После утверждённого концепта покажи ровно три визуально разных направления с изображениями. Отрази референс автора в одном из них, для двух других предложи самостоятельные решения. Укажи для каждого камеру, палитру, силуэты и читаемость игрового действия.

## Материалы и решение

Используй предоставленные изображения или найденные доступными инструментами реальные примеры. Сохраняй URL источника и поясняй, что берём: камеру, масштаб, палитру, композицию или читаемость действия. Генерируемые концепты необязательны и явно помечаются. Референс не означает право включить картинку в готовую игру.

Если локальной копии нет, покажи разрешённый просмотр источника. Для каждого направления нужны изображения. Если материал недоступен, попроси недостающий референс и оставь этап открытым.

Спроси, какой из трёх вариантов выбрать и что исключить. Дождись решения автора.

## Автономный HTML без сервера

`scripts/build_reference_board.py` работает на стандартной библиотеке Python: встраивает PNG/JPEG/GIF/WebP, экранирует подписи и ссылки, не скачивает файлы и не запускает программы. Пути изображений задаются относительно JSON-манифеста либо абсолютным путём. Существующий HTML не перезаписывается без `--replace`.

Пример из корня клона набора, PowerShell:

```powershell
python .\skills\game-creator\scripts\build_reference_board.py .\skills\game-creator\assets\reference-board\board.json --output .\board-preview.html
Start-Process -FilePath (Resolve-Path -LiteralPath .\board-preview.html).Path
```

После установки в проект путь к помощнику начинается с `.agents/skills/game-creator/`. В `assets/reference-board/` находятся только схематические примеры камеры для проверки инструмента, а не референсы реальной игры. Для новой игры замени их подходящими изображениями.

Формат собственного UTF-8 JSON (пути и URL должны быть реальными):

```json
{"title":"Направление игры","directions":[{"id":"arena","name":"Арена сверху","notes":"Камера и читаемость боя","images":[{"path":"images/arena.png","caption":"Масштаб героя","source":"https://example.com/reference","kind":"reference"}]}]}
```

`kind`: `reference`, `generated` или `user`. `source` — HTTP(S)-ссылка для атрибуции; можно не указывать для локального изображения. Не заявляй проверенную лицензию без источника.

Пользователь отвечает в чате по ID либо выбирает вариант на доске и скачивает JSON. У доски нет backend: Codex не получает скачивание автоматически. Прочитай файл по сообщённому пользователем пути или используй ответ в чате. Ни один вариант не выбран по умолчанию.

## Сохранение и переход к MVP

В art-direction.md сохрани путь к доске, три строки вида `A. Название — источник изображения и визуальные признаки`, с латинскими A, B и C, источники, выбранный стиль и исключения. В docs/game/state.json запиши `visual_choice` ("A", "B" или "C"). Сохраняй остальные поля состояния.
