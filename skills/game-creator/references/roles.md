# Роли и включение по потребности

| Задача | Навык | Когда подключать |
|---|---|---|
| Идея и последовательность работы | game-creator | Старт или продолжение всей игры |
| Аналоги, ниша, игроки, референсы | game-market-research | Перед концептом и при новой рыночной гипотезе |
| Концепт, механика, правила | game-design | Перевод идеи в конкретный игровой опыт |
| Гипотеза, границы, Feature Index | game-mvp | До реализации и при изменении объёма |
| HTML, Canvas, Phaser, Three.js | game-web-builder | Первая браузерная реализация |
| Визуальное направление и 2D | game-art-director | Когда нужны читаемость и согласованные ассеты |
| Меню, HUD, onboarding, доступность | game-ui-design | Когда UI влияет на игровые действия |
| Звук и музыка | game-audio | Когда звуковая обратная связь нужна тесту |
| Ассет-пайплайн | game-asset-pipeline | Импорт, бюджеты и происхождение файлов |
| Модели, материалы, UV, риг, анимация | blender-core → blender-* | Когда реально нужны 3D-ассеты; заканчивать asset-qa |
| Unity Editor и C# | unity-mcp-orchestrator | Если установлен соответствующий профиль и доступен Editor/MCP |
| Roblox, Luau, импорт, сервер | game-roblox | Для реализации или продолжения Roblox-проекта |
| Mobile, touch, устройства, выпуск | game-mobile | Когда мобильный запуск становится текущей задачей |
| Перенос между движками/площадками | game-platform-port | После выбора исходной и целевой среды |
| QA, поведение и проверка гипотезы | game-qa | После каждого замкнутого среза |
| Позиционирование и маркетинговый тест | game-marketing | Когда есть конкретная аудитория и обещание |

Проверяй наличие SKILL.md в текущем окружении. Отсутствующий профиль не объявляй установленным: либо выполни работу доступными средствами, либо дай точную команду установки профиля из клона набора. Для браузера используй доступный browser connector/CUA/Playwright. Для Phaser проверяй реальную major-версию перед чтением предметных phaser-*; включённые инструкции рассчитаны на Phaser 4. Для Blender включён upstream под 5.2+, на другой версии нужны её API и адаптация.

Если уже доступны imagegen, Figma, Adobe или другие сервисы, используй их подходящий skill и подключённые инструменты. Набор не включает платные учётные записи и сам не устанавливает MCP. Общие команды поиска инструментов зависят от текущего хоста; не выдумывай имена tools.
