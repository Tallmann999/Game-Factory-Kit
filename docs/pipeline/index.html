          Подключить игру

          В чате проекта скажите «Покажи конструктор». Для запуска вручную откройте терминал в папке набора и укажите папку своей игры.

          node scripts/project.cjs "путь/к/игре"

          Откройте адрес из терминала. Конструктор прочитает документы этой игры и сохранит схему в её папке.

          В какую ветку отправлять фичи?

          После приёмки каждой фичи Робокоп обновляет Feature Index, создаёт один коммит и делает push.

          Как выполнять фичи?

          Для работы с игрой используйте JSON проекта и откройте доску командой из README. Там появятся карточки из Feature Index.
          Передача работы

          Задание для Codex

          Скачайте задание в папку игры и передайте его Codex. Координатор получит порядок этапов, исполнителей и правила вопросов.

          Запустить исполнителя в терминале
          Скачайте JSON в папку игры. В терминале из папки набора выполните команду, указав свои пути. После сеанса откройте обновлённый JSON в конструкторе.
          node scripts/run-pipeline.cjs "путь/к/game-pipeline.json" --project "путь/к/игре"
