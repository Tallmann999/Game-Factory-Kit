# Mage: Cleanse the Corruption

Status updated: 2026-08-28

## Player promise

Игрок — боевой маг, который выбирает подходящую стихию, быстро уничтожает заражённых врагов и очищает один участок мира за другим.

## Current playable state

Существует браузерный прототип одного экрана: игрок выбирает оружие мага, атакует противника, получает деньги и усиливает урон. Карта, участки и полноценная анимация относятся к следующему развитию прототипа.

## Current milestone

M0: доказать, что выбор стихии, быстрые убийства, выпадение денег и покупка улучшения образуют понятный повторяемый цикл.

## Constraints

- Engine: web
- Platform: desktop browser; будущая цель — Yandex Games
- Genre: one-screen clicker / incremental
- Stage: prototype
- Art: 2D sprites; на первом этапе допустим один idle-кадр
- Scope: маленькая законченная игра для портфолио соло-разработчика

## Scope boundary

### Now

- Один противник одновременно.
- Выбор из трёх стихий: Bio, Crystal, Cleanse.
- HP врага, имя, уровень и читаемый результат попадания.
- Деньги за убийство и одно улучшение урона.
- Появление следующего врага после короткой паузы смерти.

### Next

- Десять врагов на участке и переход между открытыми участками.
- Полоса участков в верхней части игрового экрана.
- Отдельные idle, hit и die-анимации.

### Later

- Карта биомов, боссы, больше оружия, контентная прогрессия и публикация на Yandex Games.

### Not in this version

- Двадцать биомов, сложная экономика, социальные функции и серверная часть.

## Assumptions and open questions

- Для первого теста достаточно мыши и desktop viewport.
- Бонус совпадающей стихии должен быть заметен без длинного обучения.
- Точный баланс стоимости улучшений определяется после 5–10 коротких плейтестов.
